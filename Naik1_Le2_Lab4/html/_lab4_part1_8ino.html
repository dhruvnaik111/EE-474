Detailed Description

Manage and schedule tasks with preemptive scheduling algorithms in FreeRTOS.

Authors
Dhruv Naik, Ethan Le
Date
02/28/2026

Implements Shortest Remaining Time First (SRTF) scheduling to manage three concurrent tasks: LED control, counter display, and alphabet printing.

void alphabetTask ( void * arg)

Print letters A through Z to Serial every 13 seconds.

Executes every 13 seconds to print the next letter in the alphabet sequence. After reaching 'Z', the sequence automatically restarts at 'A'. Updates remaining execution time before suspending.

void counterTask ( void * arg)

Display an incrementing counter on the LCD every 2 seconds.

Executes every 2 seconds to display a counter value (1-20) on the LCD. Updates the remaining execution time before suspending. Counter automatically resets to 0 after reaching 20.

◆ ledTask()

void ledTask ( void * arg)

Toggle an LED when its execution period expires.

Executes for 500ms every scheduling cycle. The task maintains its own remaining execution time, which decreases by 250ms per slice, and suspends itself when the slice completes to allow the scheduler to select the next task.

◆ scheduleTasks()

void scheduleTasks ( void * arg)

Implement Shortest Remaining Time First (SRTF) scheduling algorithm.

Scheduler examines all suspended tasks and resumes the task with the smallest remaining execution time. This ensures fair allocation and preemptive scheduling. Task remaining times are reset within each task when execution completes.
