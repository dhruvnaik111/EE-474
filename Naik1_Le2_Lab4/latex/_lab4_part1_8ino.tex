Implement Shortest Remaining Time First (SRTF) scheduling algorithm. 

Scheduler examines all suspended tasks and resumes the task with the smallest remaining execution time. This ensures fair allocation and preemptive scheduling. Task remaining times are reset within each task when execution completes.
